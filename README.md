# Twibbon Photo Editor - FINTRAC 2026

Web aplikasi editor twibbon interaktif untuk peserta **FINTRAC 2026 (Financial Trading Competition)** yang diselenggarakan oleh KSPM Universitas Harkat Negeri.

## Fitur Utama
* **Editor Interaktif**: Geser (drag), perbesar (pinch/zoom), putar, dan cermin (flip selfie).
* **Auto-Fit Circle Cutout**: Posisi foto otomatis pas di tengah lingkaran cutout frame (2048 x 2560 px).
* **Client-Side & Aman**: Pemrosesan gambar 100% di browser pengguna tanpa upload ke server (privasi terjaga).
* **Export HD**: Unduh hasil twibbon resolusi tinggi (2048 x 2560 px) siap upload ke Instagram / WhatsApp.
* **Mobile-Friendly**: Responsif di smartphone dan desktop.
